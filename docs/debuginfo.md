## Chrome

1. Open Authenticator
2. Right click Authenticator and click "Inspect"

![step2](../src/assets/debuggingscreenshots/chrome/step2.PNG)

3. Go to the "Console" tab

![step5](../src/assets/debuggingscreenshots/chrome/step3.PNG)

4. Copy and paste any messages into the issue description

![step4](../src/assets/debuggingscreenshots/chrome/step4.PNG)

## Firefox

1. Go to `about:debugging`
2. Check the box that says "Enable add-on debugging"

![step2](../src/assets/debuggingscreenshots/firefox/step2.PNG)

3. Click the link that says "Debug" under Authenticator 

![step3](../src/assets/debuggingscreenshots/firefox/step3.PNG)

4. Click "Ok"

![step4](../src/assets/debuggingscreenshots/firefox/step4.PNG)

5. Make sure that you are on the console tab

![step5](../src/assets/debuggingscreenshots/firefox/step5.PNG)

6. Open Authenticator again
7. Copy and paste any messages into the issue description

![step7](../src/assets/debuggingscreenshots/firefox/step7.PNG)
