Shield Authenticator is an in-browser One-Time Password (OTP) client. Shield Authenticator supports both Time-Based One-Time Password (TOTP, specified in [RFC 6238](https://tools.ietf.org/html/rfc6238)) and HMAC-Based One-Time Password (HOTP, specified in [RFC 4226](https://tools.ietf.org/html/rfc4226)).

In other words, Shield Authenticator can serve as a drop-in replacement for apps such as Google Authenticator.

## Key Features

- Add accounts by scanning QR codes
- Encrypt data with a password
- Sync data between browsers
- Backup data to cloud services or export data to a file
- Smart filtering and search
- Battle.net and Steam support
